# 🗄️ 云浮市公安局警情大数据离线研判平台 (yf-map)

本系统是专为**云浮市公安局巡防管控与警情研判**设计的轻量级、完全离线式地图大数据研判大屏。系统使用 **React + TypeScript + Vite** 构建前端，利用 **Docker + Nginx** 进行容器化封装，底图适配 **CGCS2000 (国家2000大地坐标系)** 高德离线空间投影，专为公安网等无网隔离环境下的物理摆渡部署设计。

---

## 🌟 系统核心功能与特色

1.  **纯离线高德街道底图**：支持在无互联网的公安内网中，由 Docker 容器内 Nginx 静态服务代理本地离线的 XYZ 格式瓦片图层（云城区支持最高 18 级终极精细街道画面）。
2.  **金仓数据库 (Kingbase V8) 动态同步**：通过 `sync_police_data.py` 脚本，可一键读取金仓数据库警情表，免除繁琐的手工导出。
3.  **处警流水分离与算法清洗**：直接集成 `clean_replies.py` 清洗引擎，对处警情况 (`replies`) 的嘈杂 ASCII 时间流水进行剥离，提取纯净的现场处置结果，并判定数据质量标签。
4.  **警情时空时序分析轴**：底部集成全天 24 小时时间轴，支持**时空轨迹自动播放**，动态展示警情聚散迁移态势。
5.  **警情映射分类控制**：支持对 `case_type_config` 进行多选过滤，并可通过 Radio 控件自由切换**“原始警情码 (neworicharasubclass)”**或**“确认警情码 (newcharasubclass)”**进行落图比对。
6.  **清洗效果对比面板**：点击任意警情，可在右侧直观对比“报警原文”与“清洗后处警内容”的差异，协助人工校准。

## 📂 摆渡部署最小文件清单

为了顺利通过公安网光闸/网闸的安全审计并快速部署，Windows 桌面 `zhian-map` 文件夹中**已过滤了非必要的构建源码，仅保留以下运行必需资产**：

| 文件/文件夹名称 | 文件类型 | 必须性 | 用途说明 |
| :--- | :--- | :--- | :--- |
| **`yf-map-latest.tar`** | Tar 归档 (26MB) | **必须** | **Docker 离线镜像**。已烧录 React 大屏网页静态包与内部 Nginx 配置。 |

## 🚀 局内网 Linux 服务器部署三步走

把上述清单中的文件摆渡并拷贝至内网 Linux 服务器的同一目录下（例如 `/home/police/zhian-map/`），然后运行部署：

### 第一步：一键运行容器
```bash
# 1. 进入部署目录
cd /home/police/zhian-map/

# 2. 使用管理员权限运行部署脚本 (会自动加载镜像并绑定 5007 端口)
sudo ./deploy.sh
```

### 第二步：数据源验证
*   **浏览器访问**：在局域网内任意终端，输入 `http://[服务器内网IP]:5007` 即可打开警情大数据研判大屏。
*   **查看运行状态**：使用 `docker ps` 应能看到 `yf-map-system` 容器处于 `Up` 状态。

### 第三步：配置金仓数据库定期自动同步（可选）
如果您需要在内网环境与真实的 **人大金仓 V8 数据库**（Oracle 兼容模式）进行实时同步：
1.  确保内网 Linux 服务器安装了 Python 3 及 `psycopg2` 驱动：
    ```bash
    sudo pip3 install psycopg2-binary
    ```
2.  在服务器终端或配置在 `/etc/crontab` 定时任务中，配置金仓环境变量并执行同步脚本：
    ```bash
    export KINGBASE_HOST="10.x.x.x"     # 数据库主机IP
    export KINGBASE_PORT="54321"         # 端口
    export KINGBASE_DBNAME="ywdata"      # 库名
    export KINGBASE_USER="user"          # 用户
    export KINGBASE_PASSWORD="password"  # 密码
    
    # 运行同步 (脚本会自动覆盖同目录下的 incidents.json 与 case_type_config.json)
    python3 sync_police_data.py
    ```
    *注：脚本覆盖 JSON 文件后，因为 Docker 容器中已经挂载了这两个文件，您**无需重启 Docker 容器**，直接在浏览器刷新页面即可看到最新清洗后的警情数据！*

## 🗺️ CGCS2000 空间坐标自适应机制
*   **双向纠偏**：金仓数据库存储的警情坐标为 **CGCS2000 / WGS-84** 标准 GPS 坐标，而离线高德瓦片基于 **GCJ-02** 加密投影。
*   **自动换算**：平台前端已集成双向纠偏算法。当警情点落图时，自动转换为 GCJ-02 投影渲染；当您在地图上点击交互打标时，产生的坐标会**自动反向纠偏为 CGCS2000 经纬度**写入表单。您在内网数据库直接导入或从警务通接收到的坐标可直接无偏差使用。
